# Contributing

Thanks for helping improve this portfolio.

## Getting started

1. Fork or clone the repository.
2. Install dependencies with `npm install`.
3. Run the development server with `npm run dev`.
4. Make a focused change and test it locally.
5. Open a pull request with a clear description of the change.

## Pull requests

Please keep pull requests focused on one improvement. Include:

- What changed
- Why the change was needed
- How it was tested

Avoid committing secrets, local environment files, or generated build output.
