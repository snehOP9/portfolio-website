# Development Guide

## Common commands

- `npm install` — install dependencies
- `npm run dev` — start the development server
- `npm run check` — run TypeScript checks
- `npm run build` — create a production build

## Before opening a pull request

1. Run `npm run check`.
2. Run `npm run build` when the change affects the application build.
3. Check the affected pages in the browser.
4. Keep the PR focused and describe how the change was verified.
