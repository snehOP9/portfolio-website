# Accessibility Checklist

Use this checklist when adding or changing portfolio pages and components.

## Content

- Use meaningful heading levels in order.
- Give links descriptive text.
- Provide useful alternative text for informative images.
- Keep decorative images from being announced unnecessarily.

## Interaction

- Ensure interactive controls can be reached with a keyboard.
- Keep visible focus states.
- Use buttons for actions and links for navigation.
- Do not rely on hover alone to reveal important information.

## Forms

- Associate labels with inputs.
- Provide clear validation messages.
- Preserve useful focus behavior after validation errors.

## Visuals

- Maintain readable text contrast.
- Avoid communicating information by color alone.
- Check layouts at narrow viewport widths.

Run the project's checks after accessibility changes and manually test the affected page with keyboard navigation.
