# Spatial architecture

The portfolio uses vector-based spatial systems rather than heavyweight remote models. The hero uses a custom S path with layered metallic material, back and front orbit passes, depth-like shadowing, and pointer parallax. It is deliberately asset-light and works in a static GitHub Pages export.

Project previews are procedural SVG signal systems. They are not represented as production simulations or as a claim of WebGL. This choice keeps the site resilient on low-GPU devices while preserving real-time, project-specific motion. Each preview has one DOM/SVG scene, uses IntersectionObserver to pause outside the viewport, and has a reduced-motion static state.

No downloaded models, remote texture CDNs, or licensed 3D assets are required.
