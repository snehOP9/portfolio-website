# Anony Talk scene

- **Purpose:** anonymous posts, peer chat, avatar expression, relate interactions, and optional conversational support.
- **Architecture:** React/Vite client → Express API → SQLite with bcrypt authentication.
- **User action:** share anonymously, relate to a post, or connect through peer chat without exposing a real identity.
- **Visual:** privacy-shell avatar nodes exchange short-lived message packets across a community field.
- **Motion:** quiet avatar drift, dotted relationship paths, moving packet; card click opens details.
- **Color/material:** soft green light inside dark privacy shells.
- **Fallback:** static, non-clinical community field; reduced motion and offscreen scenes pause.
- **Cost:** procedural SVG only; no faces, medical symbols, or unsupported clinical implication.
