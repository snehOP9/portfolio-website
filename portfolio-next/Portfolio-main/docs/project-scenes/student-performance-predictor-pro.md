# Student Performance Predictor Pro scene

- **Purpose:** estimate student risk, uncertainty, and tailored intervention ideas from a learning snapshot.
- **Architecture:** React/Vite UI → FastAPI endpoints → model and conformal artifacts → explanation/recommendation responses.
- **User action:** submit a validated learning snapshot and inspect prediction, uncertainty, and recommendation outputs.
- **Visual:** feature chips enter transparent model layers and form an output guidance ring.
- **Motion:** feature drift, slow model-plane breathing, 14-second output ring; card click opens details.
- **Color/material:** cool green signals, translucent layered panels.
- **Fallback:** static feature-to-guidance composition; reduced motion and offscreen scenes pause.
- **Cost:** procedural SVG, no invented student records or remote assets.
